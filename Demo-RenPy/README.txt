Откройте эту папку как проект в Ren'Py Launcher. Нажмите Проверить сценарий, затем Запустить. Для дистрибутива используйте Build Distributions. Внутри нет самого движка. Python-плагины исполняются игрой: подключайте только доверенный код. Steam требует Steam support из Launcher и настройки Steamworks. MP4 поддерживается не на всех платформах, используйте WebM VP9/Opus или OGV.
