# NovelForge

Локальный конструктор визуальных новелл для Ren’Py. Редактор работает в браузере, сохраняет проект на компьютере и экспортирует настоящий проект Ren’Py с редактируемыми файлами `.rpy`.

## Запуск на Windows

1. Распакуйте присланный вами `renpy-8.5.3-sdk.zip`.
2. Распакуйте NovelForge рядом с папкой `renpy-8.5.3-sdk`.
3. Запустите `Start-Windows.bat`. Он использует Python из SDK, поэтому отдельная установка Python не нужна при таком расположении папок.
4. Откроется `http://127.0.0.1:8765`. Окно командной строки оставьте открытым.
5. Если SDK лежит в другом месте, запустите `Start-From-SDK.bat` и вставьте путь к его папке без кавычек. Например `D:\Tools\renpy-8.5.3-sdk`.

Альтернатива: установленный Python **3.10+**, команда `python app.py`. Зависимостей pip нет. Движок Ren’Py в этот небольшой архив повторно не включен: используйте свой приложенный SDK. Для старого SDK 7 запускайте сам редактор через Python 3.10+ или интерпретатор SDK 8, а SDK 7 подключайте только для проверки и запуска экспортируемой игры.

Linux: `sh start.sh`; рядом с SDK 8 будет использован его интерпретатор. macOS: `python3 app.py`, затем подключите SDK во вкладке «Экспорт». Параметры: `--sdk /путь/к/SDK`, `--port 8766`, `--no-browser`. Сервер слушает только локальный адрес.

## Что есть в программе

- Проекты, автоматическое сохранение, отмена и повтор, последние 30 резервных версий, перенос ZIP и восстановление JSON из истории.
- Сценарий: сцены, перемещение событий, дублирование, карта связей, реплики, фоны, показ и скрытие героев, три позиции, эффекты, музыка, звуки, паузы, дни, выборы, переходы, условия, переменные и концовки.
- Импорт Word `.docx`: русскоязычный шаблон с отдельными колонками для команд, объектов, текста и параметров. Доступен в обзоре. Выгрузка текущего сценария в расширенный двухколоночный Word для точного обмена всеми полями.
- Персонажи: имя, цвет имени, рост и спрайт. Мастерская простых иллюстрированных спрайтов: кожа, волосы, прическа, одежда и выражение лица; экспорт прозрачного PNG.
- Фоны: площадка, комната, город, лес, чистый фон; цвета, прямоугольники, круги, надписи, перетаскивание и размеры объектов; экспорт PNG.
- Видеозаставка и видео по событиям. Если ролика нет — конструктор последовательности карточек с фоном, изображением, текстом и временем. Сюжетные катсцены вызываются по ID. Титры редактируются отдельно.
- Собственный интерфейс Ren’Py: три цветовых шаблона, меню, сохранение и загрузка, настройки звука и скорости текста, быстрое меню, диалоговое окно, варианты выбора, уведомления. Размеры и позиция текстового окна редактируются; HUD поддерживает надписи, шкалы переменных и кнопки перехода в сцены с перетаскиванием.
- Мини-игры: викторина, кликер, попадание в движущуюся зону, ловля волейбольного мяча платформой. Настраиваются цель и время, результат записывается в сюжетную переменную. Предпросмотр есть и в браузере, и в экспортируемой игре.
- Python: подключение `.py` функции без аргументов с возвратом результата либо `.rpy` label с `call screen`. Модуль вызывается событием сценария. Примеры находятся в `examples`.
- Достижения Ren’Py: регистрация, выдача событием, синхронизация, уведомление; API-имя достижения и App ID Steam.
- Проверка структуры и ресурсов; проверка через Ren’Py lint; запуск через SDK; ZIP проекта Ren’Py, готовая демонстрационная новелла в `Demo-RenPy`.

## Первый проект за несколько минут

Откройте демо «Лето на площадке». Выберите «Сценарий» → «Знакомство» → реплику Анны и замените текст. Откройте «Предпросмотр», пройдите выбор и мини-игру. Во вкладке «Персонажи» создайте своего героя. Загрузите его картинку в «Ресурсы» или нарисуйте спрайт в мастерской, сохраните PNG и назначьте персонажу.

В сценах добавляйте события кнопкой снизу. Например: «Фон», «Показать героя», «Реплика», «Выбор». Каждый выбор ведет в сцену по ее ID. Для переменных подходят числа, строки и логические значения. Условие `trust >= 3` выбирает одну из двух сцен. Событие «Изменить переменную» с выражением `trust + 1` повышает доверие. Переход, выбор, условие и концовка завершают текущую ветку; события после них недостижимы. Конец сцены без перехода завершает игру.

Изменение ID объектов через формы обновляет ссылки на них. После удаления объекта проверьте оставшиеся ссылки кнопкой «Проверить проект».

## Word

Скачайте шаблон в обзоре либо откройте `templates/scenario-template.docx`. Одна строка — одна команда. Пример:

| Команда | Объект ID | Текст или файл | Параметры |
| --- | --- | --- | --- |
| Персонаж | anna | Анна | цвет=#b7a4ff; спрайт=anna.png; рост=средний |
| Сцена | arrival | Знакомство | |
| Фон | | court.png | эффект=плавно |
| Показать | anna | | позиция=справа |
| Реплика | anna | Привет! | |
| Переход | finish | | |
| Сцена | finish | Финал | |
| Концовка | | До встречи! | титры=да |

Для выбора пишите варианты на отдельных строках в ячейке текста: `Пойти в парк -> park`. В условии текст — выражение, параметры — `да=win; нет=finish`. Для изменения переменной объект — ее ID, текст — `trust + 1`. Для мини-игры объект — ID настроенной в программе мини-игры, параметры — `результат=trust`. Поддерживаются русские команды из руководства программы и английские имена событий.

Импорт заменяет все сцены, обновляет персонажей и другие объявления по ID, сохраняет интерфейс и существующие ресурсы. Перед импортом создается копия. Файлы ресурсов предварительно загрузите в программу: автоматического извлечения изображений из Word нет. Word `.doc` сначала сохраните как `.docx`. Текст без таблицы команд автоматически в события не преобразуется.

При расширенном экспорте Word объявления идут до первой `scene`; после начала сцены `minigame`, `cutscene`, `achievement` и `python` считаются вызовами событий. Файлы со сценарием и Python исполняются разными подсистемами: Word никогда не исполняет Python-код на стороне редактора.

## Сборка игры

Во вкладке «Экспорт» проверьте проект. Укажите путь к папке SDK, содержащей `renpy.py`, нажмите «Подключить SDK» → «Проверить через SDK» → «Запустить игру». В случае сбоя запуска журнал находится в `projects/ID/run.log` и `projects/ID/build/log.txt`.

Скачайте проект Ren’Py ZIP и распакуйте папку `Novel` в каталог проектов вашего Ren’Py Launcher. Обновите список, выберите проект и запустите. EXE, Linux, macOS и остальные дистрибутивы создаются средствами Ren’Py Launcher. Архив редактора — исходный переносимый инструмент, а не установщик EXE.

## Совместимость и границы

Профиль 8 рассчитан на Ren’Py 8.x, профиль 7 — на общий синтаксис Ren’Py 7.4+ и 8.x. Проверен приложенный **Ren’Py 8.5.3.26051504**. Старые SDK 7 в этой среде не установлены и не проверены. Ren’Py 6.x и автоматическое преобразование произвольных старых `.rpy` не поддерживаются. Python-модули для SDK 7 должны поддерживать Python 2.7, для SDK 8 — соответствующий Python 3. Совместимость внешних библиотек требует отдельной проверки.

Браузерный предпросмотр — помощник: он показывает одного героя за раз, упрощает эффекты и не исполняет Python, Steam и сохранения движка. В экспортируемой игре Ren’Py поддерживается одновременный показ нескольких героев. Полная проверка игры выполняется через SDK. Мастерская рисует простые двухмерные фигуры и спрайты; генерации фотореалистичных персонажей и AI-видео здесь нет. Конструктор интерфейса редактирует темы, окно текста и HUD; свободная перестройка произвольного screen language выполняется в экспортированных `.rpy`.

Видеофайлы воспроизводятся кодеками Ren’Py; WebM/OGV предпочтительнее MP4 для переносимости. Собственные Python-файлы имеют полномочия процесса игры — подключайте доверенный код. Редактор не изолирует плагины в песочнице.

Steam: установите Steam support в Launcher, настройте и опубликуйте достижения в Steamworks с теми же API-именами. Потребуются ваш App ID и доступ партнера. В комплект не входят Steam SDK и готовая публикация в магазине. Без Steam достижения остаются локальными в Ren’Py. Перед релизом удалите тестовый `steam_appid.txt` из итогового пакета согласно требованиям вашей интеграции.

## Проверки и исходный код

`python -m unittest discover -s tests -v` — модель, Word, безопасность выражений, экспорт, HTTP-операции, конфликт сохранения и перенос ZIP. При наличии Node: `node tests/test_ui.js` — генерация всех представлений и интерпретатор выражений; это не полноценный браузерный тест. Проверка экранов движком: `python tests/runtime_smoke.py /путь/к/SDK8`. Она отрисовывает меню, диалоги, выборы, все мини-игры, титры, настройки и слоты; это не полное прохождение ветвей сюжета. Для воспроизводимости lint: `renpy.sh Demo-RenPy lint` либо соответствующая команда SDK под Windows.

`app.py` — локальный сервер и сохранение; `core.py` — модель, Word и компилятор; `web/` — интерфейс; `templates/` — шаблон Word; `projects/` — данные; `examples/` — примеры интеграции.

Проект не связан с разработчиками Ren’Py. Исходные тексты конструктора предоставлены в комплекте. Сторонние движки, библиотеки и ваши ресурсы сохраняют свои лицензии.
